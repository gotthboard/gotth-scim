# gotth-scim v1.0.0 release candidate

This candidate stabilizes the existing storage-neutral SCIM 2.0 Go package as
major version 1. It does not add a product database adapter, identity provider,
authentication stack, or deployment policy.

No `v1.0.0` tag or hosted Release exists from this work. Publication remains a
separate irreversible action after admission.

## Compatibility

- The supported package is
  `github.com/gotthboard/gotth-scim/pkg/scim`.
- The exported API baseline is `api/v1.0.0.txt` and is enforced by
  `make verify-api` under Go 1.26.6.
- The v1 support, protocol, configuration, and error promises are in
  `docs/compatibility-v1.md`.
- Authentication, TLS, authorization, durable storage, provisioning scope,
  product identity/session behavior, and operational policy remain
  consumer-owned.

## Protocol correction

RFC 7644 section 3.4.2.4 requires a negative pagination `count` to be
interpreted as zero. GET and POST searches now return HTTP 200 with an empty
`Resources` array and `itemsPerPage: 0` while preserving the accurate
`totalResults`. Malformed integer values still fail, positive counts remain
capped by the configured page size, and the search-candidate limit remains in
force.

## Candidate assets

From a clean exact commit, run:

```sh
scripts/build-release-candidate.sh /absolute/output/directory EXPECTED_COMMIT EXPECTED_TREE
```

The non-overwriting builder requires the authorized full commit and tree IDs,
binds itself to that exact clean checkout, disables Git replacement and
configuration drift plus Go workspace and user configuration, verifies the
offline module cache, and emits:

- `gotth-scim-v1.0.0-source.tar.gz` — normalized Git source archive;
- `gotth-scim-v1.0.0-source-manifest.txt` — exact Git modes, types, and
  object IDs;
- `gotth-scim-v1.0.0-LICENSES.txt` — project MIT and linked
  `golang.org/x/text` BSD-3-Clause license evidence;
- `gotth-scim-v1.0.0.spdx.json` — SPDX 2.3 source/dependency SBOM;
- `gotth-scim-v1.0.0.intoto.jsonl` — unsigned in-toto Statement with the
  project-defined provenance predicate, binding commit, tree, release script,
  normalized Go environment, dependency, and asset digests; and
- `SHA256SUMS` — checksums for every preceding asset.

The provenance is evidence generated by the repository script, not a hosted
builder attestation and not a signature. Publication policy may add signatures,
but must not alter these exact candidate bytes.

## Upgrade

Before the tag exists, continue pinning the published `v0.1.0`. After
publication, upgrade explicitly:

```sh
go get github.com/gotthboard/gotth-scim@v1.0.0
```

Consumers must rerun their durable adapter conformance, database lifecycle,
authentication/authorization, and product integration gates. The library's
source compatibility promise does not certify a consumer's operational
integration.
